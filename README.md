# 학습자료 공유 서비스 v2

실행: 압축을 푼 뒤 index.html을 여세요.

구조
- index.html: 홈
- register.html: 자료 등록
- search.html: 자료 탐색
- style.css: 공통 스타일
- data.js: 과목/단원/자료 유형 데이터와 공통 함수

현재 구현
- 홈에서 등록/탐색 페이지로 실제 페이지 이동
- 과목 드롭다운과 과목별 단원 연동
- 자료 유형 선택
- 필수 입력 검증
- PDF 확장자 검증
- 등록한 자료의 메타데이터를 localStorage에 임시 저장
- 탐색 페이지에서 등록 자료 + 샘플 자료 검색/필터/정렬

현재 한계
- PDF 파일 자체는 저장하지 않음
- 새 브라우저/기기와 자료 공유 불가
- Supabase 연동 전 단계임
